# Desktop Notifications and Sounds

The desktop app can notify you when an agent:

- finishes or fails;
- asks for approval; or
- waits for structured input.

Desktop notifications and T3 Code sounds are enabled by default. Change either setting under
**Settings > General > Notifications**. Sounds are independent from native notifications, so the
app still plays a chime while you are viewing the affected thread. It hides the native notification
in that case.

Clicking a notification restores T3 Code and opens the affected thread.

Notifications and sounds work while the desktop app is open or minimized. They do not run after
the app exits. Operating-system notification permissions and quiet modes can still hide native
notifications; the T3 Code chime follows the system's media volume instead.
